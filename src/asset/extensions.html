Extensions can read and change the pages you visit — only add ones you trust. Turning an extension on or off applies to pages you open or reload afterwards. Built-in extensions can be turned off or removed; the ones provided by the browser engine can only be turned off.

Add by link or ID

Open a store, pick an extension, copy the page address and paste it here. Chrome Web Store is tried first and Edge Add-ons is the fallback when something is missing. You can also paste a direct .crx link.

Popular

Extensions run on the same engine as the pages you browse. Some store extensions rely on Chrome features this engine does not provide, so not every one will work. Every install is confirmed first, and extensions you add can be removed at any time.
